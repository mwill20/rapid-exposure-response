# Trusted sources by tier

| Tier | Source | URL | Use |
|---|---|---|---|
| 1 | CISA Known Exploited Vulnerabilities | https://www.cisa.gov/known-exploited-vulnerabilities-catalog | Confirmed exploitation; subscribe to the feed |
| 1 | NVD | https://nvd.nist.gov | CVE details, CVSS, references |
| 1 | CVE Program | https://www.cve.org | Canonical CVE records |
| 1 | Vendor / maintainer advisories | Per vendor PSIRT | Fixed versions, official mitigations |
| 1 | National CERTs (e.g., CISA advisories, CERT-EU) | https://www.cisa.gov/news-events/cybersecurity-advisories | Coordinated guidance |
| 1 | Health-ISAC (healthcare) | https://health-isac.org | Sector alerts |
| Signal | FIRST EPSS | https://www.first.org/epss | Exploit probability; low score is not "safe" |
| 2 | SANS Internet Storm Center | https://isc.sans.edu | Fast, practical early analysis |
| 2 | Reputable research and threat-intel teams | Vendor blogs | Technical detail, early exploitation reports |
| 2 | Established security press | Trade publications | Situational awareness |
| 3 | Social media, forums, leak posts, GitHub PoCs | n/a | Prepare only; never run code from these |

**Rules:** Tier 1 alone is enough to act. Tier 2 needs two independent sources or Tier 1 confirmation. Tier 3 triggers preparation only.

Keep your org's vendor PSIRT list in the org edition, not here.
